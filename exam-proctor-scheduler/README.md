# 🎓 ระบบจัดตารางผู้คุมสอบอัตโนมัติ (Exam Proctor Scheduler)

> ระบบจัดตารางผู้คุมสอบและหาจุดสมดุลทรัพยากร (Constraint Optimization & Scheduling Engine)  
> ออกแบบสำหรับผู้ประสานงานสอบที่ไม่ใช่สายไอที ใช้งานง่าย ภาษาไทย 100% พร้อมระบบประเมินจำนวนผู้คุมขั้นต่ำ

---

## ⚡ วิธีเปิดใช้งาน (รันด้วยคำสั่งเดียว)

ไม่ต้องติดตั้ง Node.js หรือ Python เพิ่มเติม สามารถเปิดใช้งานบนเครื่อง Windows ได้ทันที:

### วิธีที่ 1: ดับเบิลคลิกไฟล์
ดับเบิลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์โปรเจกต์

### วิธีที่ 2: รันผ่าน PowerShell
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
*ระบบจะเปิดเว็บเบราว์เซอร์ไปที่ `http://localhost:8080` ให้อัตโนมัติทันที*

## 🏗️ สถาปัตยกรรมระบบ (Modular Architecture)

โค้ดถูกออกแบบแยกโมดูลอิสระตาม Clean Architecture:

```
src/
├── data/              # Data Models, Reproducible Mulberry32 Seed Generator, Settings
├── rules/             # ตัวตรวจกฎ H1-H8 (Hard), S1-S7 (Soft), Unified Validator, Feasibility
├── solver/            # Greedy Most-Constrained-First Solver + Backtracking, Explainability, Min Proctor Calc
├── store/             # Reactive State, Undo/Redo (30 steps), Versioning & Diff, Audit Trail
├── io/                # Multi-sheet Excel Exporter, Printable PDF & Sign-off Sheets
├── ui/                # Dashboard, 3 Schedule Views (Grid, Personal, Workload), Modals
├── utils/             # Thai Buddhist Date & 24h Time Formatter, PRNG
└── adapters/          # จุดเชื่อมต่อระบบจริง Phase 2 (Auth, DB, Notifications, QR, Calendar)
```

## ⚖️ กฎและข้อจำกัดที่ระบบควบคุม

### Hard Constraints (ห้ามละเมิดเด็ดขาด H1 - H8)
- **H1:** ผู้คุม 1 คนอยู่ได้ห้องเดียวในเวลาที่ทับซ้อนกัน (นับรวมเวลาเตรียมห้อง prep และเก็บห้อง wrap)
- **H2:** ห้อง 1 ห้องใช้ได้ 1 รอบในเวลาเดียวกัน และจำนวนผู้สอบต้องไม่เกินความจุห้อง
- **H3:** ไม่เกินโควต้าทุกระดับ (ต่อวัน, ต่อโครงการ, ชั่วโมงสะสม)
- **H4:** ไม่จัดคนในช่วงที่แจ้งไม่ว่าง (Unavailability)
- **H5:** ห้องที่มีผู้สอบ ≤ 30 คน ใช้ผู้คุม 1 คน, > 30 คน ใช้ผู้คุม 2 คน และต้องมี "หัวหน้าห้อง (chief)" 1 คนเสมอ
- **H6:** ผู้คุมที่ทำหน้าที่ 2 รอบติดกัน ต้องมีเวลาพักขั้นต่ำอย่างน้อย 30 นาที
- **H7:** ห้องที่มีความต้องการพิเศษ (ห้องคอมพิวเตอร์ / ทางลาดสำหรับคนพิการ) ต้องจัดห้องที่รองรับ
- **H8:** ผู้คุมสำรอง 2 คนต่อรอบ ต้องไม่ถูกใช้เป็นผู้คุมหลักในรอบเดียวกัน

### Soft Constraints (ถ่วงน้ำหนักคะแนนความพึงพอใจ S1 - S7)
- **S1:** กระจายภาระงานให้สม่ำเสมอที่สุด (ลดค่าส่วนเบี่ยงเบนมาตรฐาน SD)
- **S2:** รวมงานในวันเดียวกันเพื่อลดจำนวนวันที่ผู้คุมต้องเดินทางมามหาวิทยาลัย
- **S3:** หลีกเลี่ยงการจัดงานติดกันหลายรอบโดยไม่จำเป็น
- **S4:** ผู้คุมคนเดิมอยู่ห้องเดิมตลอดวัน ลดความสับสน
- **S5:** ผสมผสานอาจารย์และเจ้าหน้าที่ในห้องที่ต้องใช้ 2 คน
- **S6:** ความเป็นธรรมข้ามวัน คนที่ได้งานน้อยกว่าในรอบก่อนหน้าจะได้รับความสำคัญก่อน

## 💡 สรุปตัวเลข: ควรมีผู้คุมสอบกี่คน?

จากการคำนวณด้วยอัลกอริทึม Binary Search Minimum Proctor Calculator:

1. **สำหรับการสอบ 10 ห้อง (2 วัน 3 รอบ/วัน):**
   - **จำนวนขั้นต่ำสุดตามทฤษฎี:** ต้องการ **24 คน** (โควต้าเต็มเพดานพอดี ไม่สามารถมีใครลาป่วยได้เลย)
   - **จำนวนที่แนะนำสำหรับการปฏิบัติงานจริง:** ควรมี **35 - 40 คน**  
     *(เพื่อให้มีส่วนเผื่อสำรอง 30-40% รองรับกรณีมีผู้คุมลาป่วยฉุกเฉิน และช่วยลดความเหนื่อยล้าโดยไม่ต้องให้ผู้คุมคนเดิมคุมวันละ 2 รอบเต็มโควต้าทุกวัน)*
   - **สัดส่วนหัวหน้าห้อง (Chief):** ควรมีผู้มีคุณสมบัติระดับหัวหน้าห้องอย่างน้อย **40%** ของจำนวนผู้คุมทั้งหมด เพื่อไม่ให้เกิดภาวะคอขวดตามกฎ H5

## 🔌 จุดเชื่อมต่อระบบจริง (Phase 2 Extensions)

โค้ดได้จัดเตรียม Interface/Adapter ไว้พร้อมสำหรับการเชื่อมต่อในระยะถัดไป:
- **ระบบล็อกอิน (SSO/OAuth):** ดูที่ `src/adapters/auth-adapter.js`
- **ฐานข้อมูลจริง (REST API/Database):** ดูที่ `src/adapters/storage-adapter.js`
- **แจ้งเตือนทาง LINE Notify / Email:** ดูที่ `src/adapters/notification-adapter.js`
- **QR Code Check-in:** เตรียม hook สำหรับผูกพิกัดเวลาเช็กชื่อจริงไว้ใน `src/data/models.js`

## 🤖 ProctorAI Agent (ผู้ช่วยจัดตารางอัจฉริยะ)

ระบบมาพร้อม AI Agent ในตัว (`src/agent/proctor-agent.js`) ที่ทำงานแบบ Local-First บนเบราว์เซอร์:
- **วินิจฉัยสุขภาพตาราง (Schedule Health & Bottleneck Diagnosis):** วิเคราะห์ข้อผิดพลาดตามกฎ H1-H8 และแจ้งเตือนจุดเสี่ยง
- **สั่งการด้วยภาษาธรรมชาติ (Conversational Prompts):** พิมพ์สั่งงานภาษาไทย เช่น *"ตรวจสุขภาพตาราง"*, *"คำนวณผู้คุมขั้นต่ำ"*, *"จัดตารางอัตโนมัติ"*
- **คำแนะนำรับมือคนลากะทันหัน (Sudden Leave Matching):** แนะนำตัวแทนที่เหมาะสมตามเกณฑ์ทักษะ CBT และความยุติธรรม
- **100% Privacy Guarantee:** ทำงานออฟไลน์ได้บนเครื่องผู้ใช้ ข้อมูลส่วนบุคคลจะไม่รั่วไหลออกนอกระบบ
